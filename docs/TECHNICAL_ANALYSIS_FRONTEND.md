# 技术分析前端页面使用指南

## 页面概览

技术分析师页面提供了完整的技术分析功能，包括：

1. **技术指标展示** - 可视化图表展示 MA、MACD、RSI、KDJ 等指标
2. **技术形态识别** - 展示识别到的头肩顶、双底等经典形态
3. **策略回测** - 对比多种技术指标策略的历史表现
4. **LLM 分析报告** - AI 生成的专业技术分析报告

---

## 访问方式

### 1. 启动前端开发服务器

```bash
cd /Users/code/python/QuantMind/frontend
npm install  # 首次运行需要安装依赖
npm run dev
```

浏览器访问: http://localhost:5173

### 2. 在左侧菜单选择

点击 **"技术分析师"** 菜单项即可进入页面。

## 页面功能详解

### 一、技术指标 Tab

#### 功能描述
展示股票的技术指标数据和可视化图表，包括均线、MACD、RSI、KDJ 等。

#### 操作步骤

1. **输入股票代码**
   - 在顶部搜索框输入股票代码（如：600519）
   - 选择分析周期：日线/周线/月线

2. **计算指标**
   - 点击 **"计算指标"** 按钮
   - 系统会调用后端 API 计算技术指标
   - 计算完成后自动加载数据

3. **查看指标卡片**
   - 顶部显示最新的技术指标数值
   - MA5、MA20、MA60：移动平均线
   - RSI14：相对强弱指数（<30 超卖，>70 超买）
   - MACD：显示金叉/死叉状态
   - KDJ-J：随机指标（<20 超卖，>80 超买）
   - ATR14：波动率指标
   - 量比：成交量对比

4. **查看图表**
   - **均线走势图**：展示 MA5、MA20、MA60 的走势
   - **MACD 指标图**：展示 DIF、DEA、MACD 柱
   - **RSI & KDJ 图**：展示摆动指标，自动标注超买超卖区域

#### 图表说明

**均线走势图**
- 蓝色线：MA5（短期趋势）
- 绿色线：MA20（中期趋势）
- 黄色线：MA60（长期趋势）
- 多头排列：MA5 > MA20 > MA60（看涨）
- 空头排列：MA5 < MA20 < MA60（看跌）

**MACD 图**
- 蓝色线：DIF（快线）
- 绿色线：DEA（慢线）
- 红色/绿色柱：MACD 柱（红色为正，绿色为负）
- 金叉：DIF 上穿 DEA（买入信号）
- 死叉：DIF 下穿 DEA（卖出信号）

**RSI & KDJ 图**
- 紫色线：RSI14
- 蓝色线：KDJ-K
- 绿色线：KDJ-D
- 黄色线：KDJ-J
- 虚线标注：20/30/70/80 关键位

---

### 二、技术形态 Tab

#### 功能描述
自动识别股票K线中的经典技术形态，如头肩顶、双底、三角形等。

#### 操作步骤

1. **识别形态**
   - 点击顶部 **"识别形态"** 按钮
   - 系统会分析最近 120 天的 K线数据
   - 识别 5 种经典技术形态

2. **查看形态列表**
   表格展示识别到的所有形态，包含：
   
   - **形态类型**：
     - 头肩顶（看跌）
     - 双底（看涨）
     - 双顶（看跌）
     - 上升三角形（看涨）
     - 下降三角形（看跌）
   
   - **状态**：
     - 形成中：形态尚未完成
     - 已确认：形态确认，可以交易
     - 已破坏：形态失效
   
   - **目标价**：根据形态计算的理论目标价位
   - **止损位**：建议的止损价位
   - **置信度**：形态识别的可信程度（0-100%）

3. **解读形态**
   - 绿色进度条（80%+）：高置信度，可以重点关注
   - 黄色进度条（60-80%）：中等置信度
   - 红色进度条（<60%）：低置信度，谨慎参考

4. **交易建议**
   - **看涨形态**（双底、上升三角形）：
     - 等待形态确认后买入
     - 目标价为理论目标位
     - 止损设在关键支撑位下方
   
   - **看跌形态**（头肩顶、双顶、下降三角形）：
     - 等待形态确认后卖出
     - 目标价为理论目标位
     - 止损设在关键阻力位上方

---

### 三、策略回测 Tab

#### 功能描述
对 7 种技术指标策略进行历史回测，找出表现最好的策略。

#### 操作步骤

1. **启动回测**
   - 点击顶部 **"策略回测"** 按钮
   - 系统会自动测试以下策略：
     1. 均线交叉
     2. MACD 金叉
     3. RSI 超买超卖
     4. KDJ 超买超卖
     5. 布林带突破
     6. 均线+MACD 组合
     7. 三重组合策略

2. **查看回测结果**
   回测完成后，弹出模态框展示结果：
   
   - **排名**：前三名有奖杯图标
   - **策略类型**：策略名称标签
   - **年化收益**：最关键指标（绿色为正收益，红色为负收益）
   - **夏普比率**：风险调整后收益（>1.0 较好）
   - **最大回撤**：历史最大跌幅
   - **胜率**：盈利交易占比
   - **交易次数**：历史交易笔数

3. **解读回测数据**
   
   **年化收益**
   - \>20%：优秀
   - 10-20%：良好
   - 5-10%：一般
   - <5%：较差

   **夏普比率**
   - \>2.0：非常好
   - 1.5-2.0：好
   - 1.0-1.5：尚可
   - <1.0：差

   **最大回撤**
   - <10%：风险较小
   - 10-20%：中等风险
   - \>20%：风险较大

   **胜率**
   - \>60%：高胜率策略
   - 50-60%：中等
   - <50%：低胜率

4. **选择策略建议**
   
   综合考虑以下因素：
   - 年化收益要高
   - 夏普比率要大于 1.5
   - 最大回撤要小于 20%
   - 交易次数要大于 10 次（样本量充足）
   
   **示例**：
   ```
   如果看到：
   - 均线+MACD组合：年化 28%，夏普 1.85，回撤 -15%，胜率 62%
   - RSI 超买超卖：年化 15%，夏普 1.2，回撤 -18%，胜率 55%
   
   推荐选择：均线+MACD组合（综合表现更好）
   ```

5. **回测周期说明**
   - 默认回测区间：2022-01-01 至 2024-12-31（约 2-3 年）
   - 可以通过修改 `TechnicalAnalyst.tsx` 代码调整回测区间
   - 建议使用 2-3 年数据，时间太短不可靠，太长可能失效

### 四、LLM 分析报告

#### 功能描述
基于技术指标、形态、回测数据，调用 LLM 生成专业的技术分析报告。

#### 前置要求
确保后端已配置 `OPENAI_API_KEY` 环境变量。

#### 操作步骤

1. **生成报告**
   - 点击顶部 **"生成报告"** 按钮（紫色按钮）
   - 系统会收集当前股票的技术数据
   - 调用 GPT-3.5-turbo 生成报告（约 10-20 秒）

2. **查看报告**
   报告弹窗包含以下内容：

   **顶部概览卡片**
   - 股票名称和代码
   - 技术评分（0-100分）
     - 80-100：技术面强势
     - 60-80：技术面良好
     - 40-60：技术面中性
     - <40：技术面较弱
   - 趋势方向：看涨/看跌/震荡
   - 信号强度：强/中/弱

   **详细分析章节**
   
   **1. 趋势分析**
   - 基于均线排列判断趋势方向
   - 分析当前处于上升/下降/横盘阶段
   - 评估趋势的强度和持续性

   **2. 形态分析**
   - 解读识别到的技术形态
   - 说明形态的意义和目标价位
   - 指出关键的突破点和失效点

   **3. 指标分析**
   - 综合分析 RSI、MACD、KDJ 的信号
   - 判断是否超买/超卖
   - 评估动能的强弱

   **4. 成交量分析**
   - 分析量比、成交量与价格的配合
   - 判断是否量价齐升/背离
   - 评估资金流向

   **5. 支撑与阻力**
   - 基于均线和形态指出关键支撑位
   - 标注重要阻力位
   - 给出突破/跌破的观察点

   **6. 交易建议**（重点）
   - **操作建议**：买入/卖出/观望
   - **建议仓位**：如 30%、50% 等
   - **止损位**：具体价格
   - **目标位**：具体价格
   - **持仓期限**：短线/中线/长线

   **7. 风险提示**
   - 指出当前技术面的主要风险点
   - 说明什么情况下技术分析失效
   - 提醒需要观察的关键变化

3. **报告使用建议**
   
   - **技术评分 80+ 且趋势看涨**：
     可以考虑买入，参考报告中的仓位、止损、目标位建议
   
   - **技术评分 60-80**：
     可以观察，等待更明确的信号
   
   - **技术评分 <60 或趋势看跌**：
     避免买入，或考虑止损离场
   
   - **报告是辅助工具**：
     不应单独依据报告交易，需结合基本面、市场环境综合判断

## 使用场景示例

### 场景 1：技术选股

**目标**：从多只股票中选出技术面最好的。

**步骤**：
1. 依次输入多只股票代码（如 600519、000001、000002）
2. 对每只股票点击"生成报告"
3. 对比各股票的技术评分
4. 选择评分 80+ 且趋势看涨的股票

---

### 场景 2：形态交易

**目标**：捕捉双底形态的突破机会。

**步骤**：
1. 输入股票代码，点击"识别形态"
2. 在形态列表中筛选"双底"且"已确认"的记录
3. 查看置信度，选择 80% 以上的
4. 参考目标价和止损位设置交易计划
5. 等待价格突破颈线后入场

---

### 场景 3：策略验证

**目标**：验证某个技术指标策略是否有效。

**步骤**：
1. 输入股票代码，点击"策略回测"
2. 查看该策略的历史表现（年化收益、夏普、回撤）
3. 如果表现好（年化 >20%，夏普 >1.5），可以实盘使用
4. 如果表现差，说明该指标对这只股票无效，不建议使用

---

### 场景 4：多周期分析

**目标**：日线和周线双重确认趋势。

**步骤**：
1. 选择"日线"，点击"计算指标"
2. 查看日线均线排列（如 MA5 > MA20 > MA60）
3. 切换到"周线"，再次计算指标
4. 如果周线也是多头排列，说明多周期共振，趋势更可靠
5. 参考 LLM 报告的建议进行交易

## 常见问题

### Q1: 点击"计算指标"后提示"未找到技术指标数据"？

**A**: 需要先同步 K线数据，然后计算指标。

解决方法：
```bash
# 方法1: 通过 API
curl -X POST "http://localhost:8000/api/v1/sync/kline?codes=600519"
curl -X POST "http://localhost:8000/api/v1/technical/sync/indicators?codes=600519"

# 方法2: 通过前端
在"数据同步"页面先同步 K线，然后回到技术分析页面点击"计算指标"
```

---

### Q2: "生成报告"按钮点击后报错？

**A**: 需要配置 OpenAI API Key。

解决方法：
```bash
# 在 .env 文件中添加
OPENAI_API_KEY=sk-xxx
```

---

### Q3: 回测结果显示交易次数很少（<5次）？

**A**: 可能是：
1. 回测时间太短
2. 策略信号太少
3. K线数据不足

解决方法：
- 延长回测区间（修改代码中的 start_date）
- 选择交易次数更多的策略
- 确保有足够的历史 K线数据

---

### Q4: 形态识别没有结果？

**A**: 可能是：
1. 最近 120 天内没有明显的技术形态
2. K线数据不足

这是正常现象，不是所有股票都有明显的技术形态。

---

### Q5: 不同周期的指标差异很大？

**A**: 这是正常的。日线反映短期走势，周线反映中期趋势，月线反映长期趋势。

建议：
- 短线交易看日线
- 中线交易看周线
- 长线投资看月线
- 多周期共振的信号更可靠

---

## 性能优化建议

1. **首次使用先计算指标**
   - 第一次查询某只股票时，点击"计算指标"
   - 后续会增量更新，速度更快

2. **避免频繁切换周期**
   - 每次切换周期都需要重新计算
   - 确定好要看的周期再操作

3. **批量分析多只股票**
   - 如果要分析很多股票，建议使用批量 API
   - 不要在前端逐个点击
