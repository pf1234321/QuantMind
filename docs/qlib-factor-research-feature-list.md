# Qlib 因子研究功能清单

## 1. 文档目的

本文档根据 Qlib 因子研究代码 `Qlib.py`、当前 QuantMind 系统能力和因子研究原型页面整理，作为后续通过 `/opsx:propose` 拆分开发需求的功能清单。

当前研究方案固定为：

- 数据源：`trade_stock_daily`
- 数据适配：`trade_stock_daily → Qlib Adapter → Alpha158`
- 行情时间范围：`2022-01-04 ~ 2026-08-24`
- 训练集：`2022-01-04 ~ 2024-12-31`
- 验证集：`2025-01-01 ~ 2025-12-31`
- 测试集：`2026-01-01 ~ 2026-08-24`
- 因子集：固定使用 Qlib `Alpha158`
- 模型：固定使用 `LightGBM / LGBModel`
- 研究结果：必须保存任务配置、模型、预测结果、因子分析结果和回测结果

## 2. 使用方式

建议每个功能单独创建一个提案。复制对应的“提案描述”执行：

```text
/opsx:propose "提案描述"
```

开发顺序建议：先完成数据适配、研究任务和训练闭环，再实现因子分析、回测、实验管理和机会看板联动。

## 3. 功能清单

### 功能 1：`trade_stock_daily` Qlib 数据适配

**功能描述**

将业务数据库表 `trade_stock_daily` 转换为 Qlib 因子计算可使用的数据访问层，避免研究流程直接依赖默认的本地 Qlib 行情库。

具体要求：

- 从 `trade_stock_daily` 读取股票代码、交易日期、开高低收、成交量和成交额。
- 将业务字段映射为 Qlib 标准字段：`open`、`high`、`low`、`close`、`volume`、`amount`。
- 统一股票代码格式，例如 `000001` 转换为 `SZ000001` 或项目约定格式。
- 统一前复权价格口径，避免因子计算和回测使用不同复权方式。
- 支持按股票池和日期范围读取数据。
- 检查最早日期、最新日期、股票数量和交易日数量。
- 对缺失行情、重复行情和异常价格给出诊断结果。
- 不修改或覆盖原始 `trade_stock_daily` 数据。

**验收重点**

- Qlib 因子处理器可以通过适配层读取数据。
- 任意研究任务都能获得数据覆盖范围和数据质量状态。
- 数据字段和复权口径有明确记录。

**提案描述**

> 实现 Qlib 因子研究的 `trade_stock_daily` 数据适配层，从 MySQL 行情表读取标准日线数据，完成股票代码和字段映射、前复权口径统一、按股票池和日期范围查询、数据覆盖范围统计以及缺失和异常数据检查，并提供 Qlib Alpha158 可调用的数据接口，不修改原始行情数据。

### 功能 2：行情数据源状态检查

**功能描述**

在因子研究页面展示研究数据源状态，替代原型中静态的 `qlib.init()` 状态。

具体要求：

- 显示数据源名称：`trade_stock_daily`。
- 显示数据链路：`trade_stock_daily → Qlib Adapter → Alpha158`。
- 显示数据库连接状态。
- 显示行情最早日期和最新日期。
- 显示股票总数、交易日数量和数据总条数。
- 显示数据质量状态：正常、缺失、异常或不可用。
- 显示最近一次数据同步时间。
- 训练任务开始前重新检查数据覆盖范围。
- 数据范围不足时禁止创建训练任务或提示用户确认。

**提案描述**

> 实现因子研究数据源状态检查功能，从 `trade_stock_daily` 统计数据库连接状态、行情覆盖日期、股票数量、交易日数量、数据总量、最近同步时间和数据质量状态，并在前端以数据源状态面板展示，训练前自动执行检查，数据范围不足时阻止任务启动。

### 功能 3：固定研究时间区间与时序切分

**功能描述**

根据现有行情范围固定研究时间，并严格按时间顺序划分训练、验证和测试数据。

具体要求：

- 研究数据范围固定为 `2022-01-04 ~ 2026-08-24`。
- 训练集固定为 `2022-01-04 ~ 2024-12-31`。
- 验证集固定为 `2025-01-01 ~ 2025-12-31`。
- 测试集固定为 `2026-01-01 ~ 2026-08-24`。
- 页面展示三个区间及其数据量。
- 时间区间不允许前端随意修改。
- 校验三个区间不能重叠，且必须按时间递增。
- 训练和验证过程不得使用测试集数据。
- 预处理器只能使用训练集拟合。
- 记录实际使用的时间区间，保证实验可复现。

**提案描述**

> 实现 Qlib 因子研究的固定时序数据切分功能，将 `2022-01-04 ~ 2026-08-24` 按训练集 `2022-01-04 ~ 2024-12-31`、验证集 `2025-01-01 ~ 2025-12-31`、测试集 `2026-01-01 ~ 2026-08-24` 划分，禁止区间重叠和前端随意修改，确保预处理拟合和模型训练不存在未来数据泄漏，并保存实际切分配置。

### 功能 4：股票池选择

**功能描述**

为研究任务提供股票池选择入口，支持系统股票池和自定义股票池。

具体要求：

- 支持沪深 A 股股票池。
- 支持沪深 300 股票池。
- 支持中证 500 股票池。
- 支持自定义股票池。
- 自定义股票池支持股票代码输入、粘贴和批量导入。
- 股票代码支持逗号、空格和换行分隔。
- 校验代码格式、是否存在于行情表以及行情覆盖是否完整。
- 显示股票池有效数量、无效数量和缺失数据数量。
- 自定义股票池需要保存到研究任务配置中。
- 训练任务执行时使用任务快照，后续股票池变化不影响历史实验。

**提案描述**

> 实现因子研究股票池管理功能，在前端增加股票池选择入口，支持沪深 A 股、沪深 300、中证 500和自定义股票池；自定义股票池支持批量输入和导入，后端校验股票代码、行情存在性和日期覆盖范围，返回有效股票清单，并将股票池快照保存到研究任务中。

### 功能 5：Alpha158 因子处理

**功能描述**

固定使用 Qlib 内置 `Alpha158`，自动生成量价因子，不开放自定义因子集。

具体要求：

- 因子集固定为 `Alpha158`。
- 页面只展示 Alpha158，不允许切换 Alpha360 或自定义因子集。
- 使用行情数据生成 158 个量价因子。
- 支持缺失值处理和无效样本剔除。
- 使用训练集拟合预处理参数。
- 支持稳健去极值、横截面标准化等 Qlib 预处理流程。
- 记录 Alpha158 版本和预处理配置。
- 统计每个阶段的样本量、因子数量和缺失率。
- 因子生成失败时记录错误并终止任务。

**提案描述**

> 实现固定使用 Qlib Alpha158 的因子生成流程，从 `trade_stock_daily` 适配数据生成 158 个量价因子，执行项目约定的缺失值处理、稳健去极值和横截面标准化，预处理参数只能使用训练集拟合，并记录因子版本、预处理配置、样本量和缺失率，不提供自定义因子集入口。

### 功能 6：LightGBM 模型配置

**功能描述**

固定使用 Qlib `LGBModel` 训练 Alpha158 因子组合预测模型。

具体要求：

- 模型固定为 `LightGBM / LGBModel`。
- 页面不提供 XGBoost、CatBoost或其他模型选项。
- 支持展示和保存学习率、叶子节点数、树数量、L1正则、L2正则和早停轮数。
- 普通用户看到核心参数，高级参数可折叠展示。
- 使用验证集执行早停。
- 保存实际使用的模型参数。
- 记录模型版本、LightGBM版本和 Qlib版本。
- 训练失败时保存错误日志。

**提案描述**

> 实现基于 Qlib LGBModel 的 LightGBM 训练功能，模型类型和 Alpha158 因子集固定，支持配置和保存学习率、num_leaves、num_boost_round、lambda_l1、lambda_l2、early_stopping_rounds等参数，使用验证集早停，记录模型版本、依赖版本、实际参数和训练错误日志。

### 功能 7：研究任务创建与异步执行

**功能描述**

将完整研究流程作为后台任务执行，避免训练和回测阻塞前端请求。

具体要求：

- 前端点击“开始训练”创建研究任务。
- 接口立即返回唯一 `run_id`。
- 后台执行数据检查、因子生成、模型训练、因子分析、回测和结果保存。
- 支持任务状态：待运行、排队中、运行中、成功、失败、取消。
- 支持阶段状态：数据检查、Alpha158、模型训练、预测、因子分析、回测、保存结果。
- 记录任务开始时间、结束时间和执行耗时。
- 支持查询实时进度和当前阶段。
- 失败任务保存错误信息和日志。
- 同一任务不能重复启动。
- 初期可使用线程池，后续可替换为任务队列。

**提案描述**

> 实现 Qlib 因子研究异步任务服务，提供创建研究任务、返回 run_id、后台执行数据检查到回测保存的完整流程，并支持任务状态、阶段状态、进度、执行耗时、错误信息、日志查询和任务取消，确保训练过程不阻塞 FastAPI 请求。

### 功能 8：模型预测与选股结果

**功能描述**

使用训练好的 LightGBM 对验证集和测试集进行预测，生成股票评分和排名。

具体要求：

- 输出日期、股票代码、预测分数和股票池排名。
- 预测分数越高表示模型预期未来收益越高。
- 分别保存训练、验证和测试预测结果。
- 支持按交易日查看预测结果。
- 支持查看 TopK 股票。
- 显示预测结果对应的模型版本和研究任务。
- 不允许使用测试区间之后的数据生成测试结果。
- 预测结果保存为数据库记录或 Parquet 文件。

**提案描述**

> 实现 Qlib LightGBM 模型预测和选股结果功能，针对训练、验证和测试区间生成日期、股票代码、预测分数和排名，支持按交易日查看 TopK 股票，保存模型版本和 run_id，确保测试预测不使用测试区间之后的数据。

### 功能 9：模型效果评估

**功能描述**

从训练集、验证集和测试集三个维度展示模型预测能力，识别过拟合风险。

具体要求：

- 展示 IC 均值。
- 展示 RankIC 均值。
- 展示 ICIR 和 RankICIR。
- 展示 IC 为正的交易日占比。
- 对比训练集、验证集和测试集指标。
- 计算训练集与测试集指标差异。
- 根据指标差异给出稳定、偏弱或可能过拟合的状态。
- 不用单一 IC 指标替代完整回测结论。
- 保存每个区间的指标结果。

**提案描述**

> 实现 Qlib 模型效果评估功能，分别计算训练集、验证集和测试集的 IC、RankIC、ICIR、RankICIR及正 IC 占比，展示三组结果对比，计算训练测试差异并识别过拟合风险，将评估指标和诊断结论保存到研究任务结果中。

### 功能 10：单因子分析与分层收益

**功能描述**

对 Alpha158 因子进行单因子诊断，展示因子的信息系数、稳定性和分层收益。

具体要求：

- 支持查看 158 个因子的指标排名。
- 展示因子 IC、RankIC、ICIR和正值占比。
- 支持按因子指标排序。
- 将股票按因子值分成 5 组或项目指定分组。
- 展示各组累计收益和多空收益。
- 展示 IC 时间序列和因子分布。
- 标识有效、稳定、较弱或反向因子。
- 明确单因子分析只用于诊断，不代表模型只使用单个因子。
- 保存因子分析报告。

**提案描述**

> 实现 Alpha158 单因子分析功能，计算 158 个因子的 IC、RankIC、ICIR、正值占比和五分组分层收益，支持因子排名、IC时间序列、分层累计收益、多空收益和因子状态展示，并将完整因子分析报告保存到研究任务中。

### 功能 11：TopK 组合回测

**功能描述**

使用 LightGBM 预测分数进行 TopK 选股回测，验证模型在组合层面的实际效果。

具体要求：

- 支持配置 TopK 股票数量。
- 支持配置调仓周期。
- 支持配置剔除数量或替换数量。
- 使用测试区间执行最终回测。
- 支持初始资金配置。
- 支持手续费、滑点和交易成本配置。
- 支持基准指数对比。
- 支持剔除 ST、停牌和新股。
- 保存每日持仓、交易记录和组合净值。
- 回测过程不得使用未来数据。

**提案描述**

> 实现基于 LightGBM 预测分数的 Qlib TopK 组合回测功能，支持 TopK、调仓周期、剔除数量、初始资金、手续费、滑点、股票过滤条件和基准指数配置，在测试区间执行无未来数据泄漏的回测，保存每日持仓、交易记录和组合净值。

### 功能 12：回测绩效报告

**功能描述**

展示组合回测的收益、风险、风险调整收益和交易统计。

具体要求：

- 收益指标：累计收益、年化收益、基准年化收益和超额收益。
- 风险指标：最大回撤、回撤持续天数、年化波动率和下行波动率。
- 风险调整指标：夏普比率、信息比率、Calmar比率和索提诺比率。
- 交易统计：交易次数、换手率、胜率、盈亏比和平均持仓天数。
- 展示策略净值、基准净值和超额净值曲线。
- 展示逐年收益。
- 展示最大回撤区间和恢复时间。
- 支持下载回测报告。

**提案描述**

> 实现 Qlib 组合回测绩效报告功能，计算并展示累计收益、年化收益、超额收益、最大回撤、波动率、夏普比率、信息比率、Calmar比率、索提诺比率、交易次数、换手率、胜率、盈亏比、逐年收益及策略与基准净值曲线，并支持报告下载。

### 功能 14：实验结果持久化与复现

**功能描述**

保存一次研究任务所需的全部配置、输入版本、模型文件和结果文件，支持历史复现。

具体要求：

- 每次实验生成唯一 `run_id`。
- 保存股票池快照。
- 保存固定时间切分配置。
- 保存 Alpha158 和预处理配置。
- 保存 LightGBM 参数。
- 保存 Qlib、LightGBM和Python依赖版本。
- 保存模型文件。
- 保存预测结果、因子分析报告和回测报告。
- 保存训练日志。
- 支持根据历史配置重新运行。
- 支持复制历史配置创建新任务。

建议目录结构：

```text
data/backtest/qlib/{run_id}/
├── model.pkl
├── predictions.parquet
├── factor_report.json
├── backtest_report.json
├── equity_curve.csv
└── training.log
```

**提案描述**

> 实现 Qlib 因子研究实验持久化和复现功能，为每次实验生成 run_id，保存股票池快照、时间切分、Alpha158配置、LightGBM参数、依赖版本、模型文件、预测结果、因子报告、回测报告和训练日志，并支持查看历史实验、复制配置和重新运行。

**功能描述**

提供历史研究任务列表，支持不同参数和模型结果的横向比较。

具体要求：

- 支持查看任务详情。

**提案描述**

> 实现 Qlib 因子研究历史实验管理功能，提供任务列表、状态筛选、股票池筛选、核心指标展示、任务详情、多个实验指标对比、历史配置复制和重新运行能力，并在删除实验时同步处理模型及报告文件且禁止删除正在运行的任务。

### 功能 16：因子结果接入机会看板

**功能描述**

将最近一次成功研究任务的预测结果转化为机会看板中的因子机会。

具体要求：

- 只使用最近一次成功任务的测试或最新预测结果。
- 按预测分数排序生成 TopK 股票。
- 展示股票代码、名称、预测分数、排名、所属行业和模型版本。
- 展示研究任务 run_id和预测日期。
- 点击股票可以跳转到个股诊断页面。
- 研究任务失败或没有成功结果时，不生成新的因子机会。
- 保留因子机会来源和生成时间。
- 不直接将训练过程中的临时结果展示到机会看板。

**提案描述**

> 实现 Qlib 预测结果接入机会看板的功能，仅使用最近一次成功研究任务的最新预测结果，按预测分数生成 TopK 因子机会，展示股票信息、预测分数、排名、行业、模型版本、run_id和预测日期，并支持跳转个股诊断，任务失败时不生成机会数据。

---

### 功能 17：研究权限与资源控制

**功能描述**

控制因子研究任务的并发、资源和访问权限，避免多个全市场任务同时占用数据库和计算资源。

具体要求：

- 限制同时运行的研究任务数量。
- 限制单个任务的最大运行时间。
- 限制股票池最大股票数量。
- 限制可提交的任务频率。
- 支持取消排队或运行中的任务。
- 研究结果按用户或工作空间隔离。
- 记录任务提交人和操作时间。
- 任务失败后释放计算资源。

**提案描述**

> 实现 Qlib 因子研究任务的并发和资源控制功能，限制同时运行任务数、单任务最大运行时间、股票池规模和提交频率，支持取消任务、任务资源释放、用户或工作空间结果隔离，并记录任务提交人和操作时间。

## 5. 建议的最小首批提案

如果准备先打通最小可用版本，建议先执行以下 7 个提案：

1. `trade_stock_daily` Qlib 数据适配
2. 固定研究时间区间与时序切分
3. 股票池选择
4. Alpha158 因子处理
5. LightGBM 模型配置
6. 研究任务创建与异步执行
7. 模型效果评估

完成这 7 项后，系统即可从页面配置股票池，使用真实数据库行情生成 Alpha158，训练 LightGBM，并查看训练、验证和测试效果。回测、实验对比和机会看板接入可作为第二批功能。

## 6. 关键约束

- 不允许前端直接执行 Qlib训练。
- 不允许训练过程使用测试集数据。
- 预处理器只能使用训练集拟合。
- Alpha158 和 LightGBM 为当前版本固定方案。
- 原始 `trade_stock_daily` 只读，研究过程不得修改行情数据。
- 每个研究任务必须保存完整配置和 `run_id`。
- IC/ICIR只用于预测能力和因子诊断，最终结论必须结合完整组合回测。
- 研究结果必须能够追溯到股票池、数据范围、模型参数和依赖版本。
